# Телеграм бот для мониторинга сервера

## Описание проекта

Проект представляет собой систему мониторинга серверов на основе Telegram-бота и кофигом в формате json.

Бот собирает:
- загрузку CPU;
- использование оперативной памяти;
- состояние сервисов;
- логирование метрик;
- отправку уведомлений при перегрузке.

## Технологии

- Python
- Telegram Bot API
- Paramiko

## Возможности

- SSH-подключение к серверу
- Мониторинг ресурсов
- Telegram-уведомления
- Ведение логов
- Выбор критического сервиса для отслеживания
